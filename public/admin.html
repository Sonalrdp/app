MacroDroid runs on your Android phone with the Airtel Payments Bank SIM/App and automatically posts every incoming credit SMS to this gateway in real-time.

Webhook Receiver URL: http://localhost:5000/api/observer/airtel
1 Install MacroDroid

Install MacroDroid from Google Play Store on your Android phone receiving Airtel Payments Bank SMS.

🛒 Open Google Play Store ↗
2 1-Click Import or Setup

Download the .macro file and tap it to import in 1 click, or create a macro with:

  • Trigger: SMS Received (Any sender or *AIRTEL*)
  • Action: Web Interactions → HTTP Request
  • Method: POST
3 HTTP Body Payload

Set Content-Type: application/json and paste this body in MacroDroid:

{ "message": "[sms_body]", "sender": "[sms_number]" }
